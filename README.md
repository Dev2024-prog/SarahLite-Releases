# Sarah Lite Releases

Ez a repository kizárólag a Sarah Lite hivatalos, aláírt kiadásait tárolja.

A forráskód nem része ennek a repositorynak. A letölthető ISO önmagában nem ad
használati jogosultságot: új Sarah pendrive készítéséhez és aktiválásához érvényes
Sarah Lite licenc szükséges.

## Kiadási fájlok

- `SarahLite-<verzió>-amd64.iso` – bootolható diagnosztikai rendszer
- `SarahUpdater-<verzió>-win-x64.zip` – Windowsos telepítő és frissítő
- `release-manifest.json` – digitálisan aláírt kiadási leíró
- `SHA256SUMS.txt` – ellenőrzőösszegek

A Sarah Updater a manifest digitális aláírását, az ISO méretét és SHA-256
ellenőrzőösszegét is ellenőrzi, mielőtt a pendrive írása elindul.

## Biztonság

Licenckulcsot, személyes adatot vagy hibajelentést ne küldj nyilvános GitHub-felületre.
